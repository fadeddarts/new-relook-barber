# New Relook Barber shop

A standalone site for New Relook Barber shop, 1054 Eglinton Ave W, Toronto. It does not share data with the Natural Barber Shop project or with `the-social-club/`.

Live site: https://fadeddarts.github.io/new-relook-barber/

```bash
npm install
npm run dev
```

The dev server uses port 5176.

Shop facts live in `src/data/`. Classic Haircut, Skin Fade, Scissor Cut, Beard Trim, and Haircut & Beard use the prices supplied for the site. Taper Fade and Complete Transformation have no published price and are marked “Price on request”.

Photographs in `public/images/` are editorial stand-ins, not pictures of the shop or of Amir. Replace them with the shop’s own photography before launch. Instagram is `@new_relook_barbershop`. TikTok is `@new.relook.barber`.
